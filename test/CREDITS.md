# Test files credits

The audio files of this folder are only used to test the plugins: they are not distributed with the plugin bundle nor the installers.

## row.wav

The row.wav file (8.6 seconds, mono, 16 kHz, 16-bit) is the following recording of the VocalSet dataset resampled to 16 kHz.

- **Title:** m10_row_spoken.wav (data_by_singer/male10/excerpts/spoken)
- **Dataset:** VocalSet: A Singing Voice Dataset (version 1.2)
- **Authors:** Julia Wilkins, Prem Seetharaman, Alison Wahl, Bryan Pardo (Northwestern University)
- **Source:** https://doi.org/10.5281/zenodo.1442513
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Modifications:** resampled from 44.1 kHz to 16 kHz.

"m10_row_spoken.wav" from "VocalSet: A Singing Voice Dataset" (version 1.2) by Julia Wilkins, Prem Seetharaman, Alison Wahl and Bryan Pardo, https://doi.org/10.5281/zenodo.1442513, licensed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Modified: resampled to 16 kHz.

J. Wilkins, P. Seetharaman, A. Wahl and B. Pardo, "VocalSet: A Singing Voice Dataset", in Proceedings of the 19th International Society for Music Information Retrieval Conference (ISMIR), Paris, France, 2018.
